# Flipit

Flipit is a flashcard app for students to create decks for their courses and fill them with question-and-answer cards. Students practise in a quiz mode that tracks which cards they know and which they still need to review.

## Run the project

## Features

- [x] List of decks (fake API with mock data)
- [x] Deck details screen (`/deck/[id]`) opened from the list
- [x] About screen and a not-found screen for wrong addresses
- [x] Shared theme with light and dark mode
- [x] Responsive layout (1, 2 or 3 columns)
- [x] FlatList with header, empty, loading and error states
- [x] Pull-to-refresh
- [x] Filter and sort chips
- [x] Long press to delete a deck
- [ ] Add and edit decks and cards
- [ ] Quiz mode with card flip
- [ ] Tabs (Decks, Profile) and a modal
- [ ] Login and data in Supabase
- [ ] Card photos and haptic feedback
- [ ] Android APK
