# Flipit

Flipit is a flashcard app for students to create decks for their courses and fill them with question-and-answer cards. Students practise in a quiz mode that tracks which cards they know and which they still need to review.

## Run the project
npm install
npx expo start

## Features
- [x] List of decks (mock data)
- [ ] Deck details screen
- [ ] Add and edit decks and cards
- [ ] Quiz mode with card flip
- [ ] Tabs (Decks, Profile) and a modal
- [ ] Login and data in Supabase
- [ ] Card photos and haptic feedback
- [ ] Android APK
